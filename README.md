KeyBindings -

Ctrl+F / Right Arrow: Move cursor right

Ctrl+B / Left Arrow: Move cursor left

Ctrl+P / Up Arrow: Move cursor up

Ctrl+N / Down Arrow: Move cursor down

Ctrl+A / Home: Move to beginning of line

Ctrl+E / End: Move to end of line

Backspace / Ctrl+H: Delete character to the left

Enter (\r): Insert newline

Ctrl+S: Set mark at current cursor position (highlighted in bold yellow)

Ctrl+G: Jump cursor to the active mark

Ctrl+C: Copy selected region (between mark and current cursor position)

Ctrl+K: Cut selected region

Ctrl+V: Paste clipboard content at current cursor position

Ctrl+O: Save file

Ctrl+X: Exit editor
